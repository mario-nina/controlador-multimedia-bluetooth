# Roadmap del proyecto

Plan de desarrollo del controlador multimedia inalámbrico Bluetooth basado en ESP32.
Cada fase valida el hardware físicamente antes de comprometerse en el esquemático.

## Estado de fases

| Fase | Descripción | Estado |
|------|-------------|--------|
| 1 | Proyecto base + primer test físico | ✓ Completada |
| 2 | Estructura de componentes | ✓ Completada |
| 3 | Control de LEDs validado + indicadores en esquemático | En curso |
| 4 | Driver de botones validado + botones en esquemático | Pendiente |
| 5 | Driver de encoder validado + encoder en esquemático | Pendiente |
| 6 | Pines confirmados + tareas FreeRTOS | Pendiente |
| 7 | BLE stack + advertising | Pendiente |
| 8 | Perfil HID Consumer Control | Pendiente |
| 9 | Integración completa — MVP | Pendiente |
| 10 | Gestión de energía + cadena de potencia en KiCad | Pendiente |
| 11 | Pruebas formales + esquemático final | Pendiente |
| 12 | PCB layout + documentación final | Pendiente |

## Hitos principales

| Hito | Fase | Descripción |
|------|------|-------------|
| MVP | 9 | Los 6 comandos funcionan end-to-end desde hardware hasta Ubuntu via BLE HID |
| Entrega final | 12 | PCB, Gerbers, memoria técnica y manual de usuario completos |
